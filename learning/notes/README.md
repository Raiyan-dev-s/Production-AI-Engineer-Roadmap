# Learning Notes

## What This Is

A place to organize your personal learning notes, observations, and insights as you work through the roadmap.

## How to Organize Notes

### Structure

```
notes/
├── README.md              ← you are here
├── python.md              ← notes on Python fundamentals
├── backend.md             ← notes on backend engineering
├── llm.md                 ← notes on LLM fundamentals
├── rag.md                 ← notes on RAG
├── agents.md              ← notes on AI agents
├── databases.md           ← notes on databases
├── deployment.md          ← notes on deployment
├── projects/              ← notes on specific projects
│   ├── my-first-api.md
│   └── rag-experiment.md
└── resources/             ← useful references
    └── cheat-sheets.md
```

### Note-Taking Tips

- **One file per topic** — keep notes focused and searchable
- **Use headings** — organize by concept, not by time
- **Code snippets** — paste code you found useful, with attribution
- **Links** — save URLs with a brief description of what's useful
- **Questions** — write down questions as they arise, answer them later
- **Mistakes** — record bugs you hit and how you fixed them (future you will thank you)

### Template for Topic Notes

```markdown
# [Topic Name]

## Key Concepts
- Concept 1: brief explanation
- Concept 2: brief explanation

## What I Learned
- Observation 1
- Observation 2

## Code Snippets
```python
# useful code here
```

## Questions / Open Items
- [ ] Question 1
- [ ] Question 2

## References
- [Link](url) — what it's useful for
```

## Completion Checklist

- [ ] Created notes for each learning section
- [ ] Notes include key concepts and code snippets
- [ ] Questions are recorded and addressed
- [ ] References are saved with descriptions
